# strata-docs

Documentacion del simulador Strata: documento maestro, prompt de trabajo para el
modelo local y checklist de validacion.

- `simulador_strata_completo.md` - documento maestro del simulador
- `prompt_simulador_strata.md` - prompt de trabajo para el modelo local
- `checklist_validacion_simulador.md` - validacion paso a paso
- `notas/` - notas de investigacion (modelos, fine-tuning, Unsloth, multi-GPU,
  detalles de Strata) y volcados de texto del W-8BEN

El codigo del motor esta en `strata-video-engine`.
